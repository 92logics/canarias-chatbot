# Prototipo estático · SER/2026/0000145362

Local demo for the published Canarias procurement of a chatbot for the future intelligent platform of support, training and guidance against gender-based violence.

This is not an official government system. It does not call any API, store questions, or invent case facts. Every reply is a fixed sentence taken from the public notice, or a refusal.

## Open

Open `index.html` in a browser. No server and no network are required. Files: `index.html`, `styles.css`, `app.js`, this `README.md`.

## Limits

The script refuses personal situations and anything not stated in the public notice. It does not simulate users, collect personal data, or give assistance. Do not treat it as a bid, a scoring tool, or a channel to the contracting authority.
